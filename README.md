About the Project

Kochwelt is a recipe website designed to bring cooking inspiration and recipes together in one place.

The application focuses on presenting recipes in an appealing and accessible way, making it easy for users to discover new meals.

Key Features

Recipe presentation

Food-related images and content

Structured recipe information

Navigation between website sections

Responsive layout
